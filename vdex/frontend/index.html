Data intelligence

Import county-level Census context into the review queue. This is not parcel ownership or active listing data.

The server must be configured with a Census API key. The key is never entered or stored in this browser.

Uses 2024 ACS 5-year estimates. Estimates and margins of error are retained. A successful fetch stages observations for human review; it does not verify property facts or grant redistribution rights.

Address-to-geography lookup

Resolve up to 20 addresses to Census geography and approximate coordinates.

Checking Census Geocoder…

No API key is documented as required. Results are geographic matches, not parcel records.

Census coordinates may be interpolated along street address ranges. They are not survey-grade or rooftop coordinates and do not establish parcel boundaries, ownership, title or property condition.
