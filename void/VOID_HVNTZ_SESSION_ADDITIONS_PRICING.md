## Hardware vs. software — an honest, important split

**Everything priced above is 100% software/development labor** — the
code, data models, and integration work. **None of it includes
physical hardware.** Hardware is a genuinely separate cost category
that scales with how many physical units actually get deployed, not a
fixed line item like software development.

### The honest, practical takeaway

**Software cost is fixed regardless of scale — build it once.**
**Hardware cost is entirely dependent on how many drones, stations,
and screens you actually deploy**, and multiplies directly with that
number. A pilot deployment of, say, 10 Port Stations with screens and
a small drone fleet could realistically run **$500,000–$1,500,000+ in
hardware alone**, using the real per-unit costs above — a genuinely
separate, much larger number than the software side, and one that
should be sized deliberately based on how many real physical
locations you actually plan to launch with, not estimated as part of
the software build.

**Recommendation**: treat software and hardware as two entirely
separate budget lines. The software gets built once and scales for
free; hardware needs a real, deliberate decision on initial deployment
size before a real total number can be finalized.
