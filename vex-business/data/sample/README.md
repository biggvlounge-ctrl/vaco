# data/sample/

Real seed/demo data goes here (Master Directive Section 5). Empty as
of Phase 1-2 — no real historical ES bar data has been sourced or
generated yet, and fabricating plausible-looking price data would be
exactly the kind of dishonesty the directive's own no-fabricated-
probability rule warns against in spirit. A real seed dataset (either
real historical ES data from a real vendor, or an explicitly-labeled
synthetic dataset for DEMO mode) is Phase 3+ scope, once the
backtest/replay engines that would consume it exist.
